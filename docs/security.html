Security

Last updated 18 November 2026

How Eight-D is built

  • Hosted on Atlassian Forge. The app's code and data run on Atlassian's infrastructure. THATCHED runs no servers for it.
  • No external endpoints. The app manifest declares no outside network access, so the app cannot send data out of Atlassian's platform.
  • Acts as the user. Jira and Confluence data is read through Atlassian's APIs as the signed-in user, so every user sees only what their own permissions allow.
  • Read-only AI tools. The Rovo agent and MCP tools only read and draft. Writes happen only when a person presses a button in the panel.
  • Open source. Anyone can read the code on GitHub.

Report a vulnerability

Please report security issues privately, not in a public issue:

  • GitHub private report: https://github.com/Tharun2075/eight-d/security/advisories/new, or
  • email business@thatched.ai with "Security" in the subject.

Include the steps to reproduce and what you saw. We aim to confirm receipt within 2 business days and will keep you told until it is fixed. Please give us a fair chance to fix it before you publish.
