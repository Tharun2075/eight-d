Support

Eight-D is free and supported by THATCHED.

Report a bug or ask a question

Open an issue on GitHub: https://github.com/Tharun2075/eight-d/issues

Email

business@thatched.ai (please do not put confidential 8D content in a public issue; use email instead)

Response time

We aim to answer within 2 business days (Monday to Friday, UK time). This is a target, not a guarantee; there is no paid service-level agreement.

What helps us help you

  • What you did, what you expected and what happened.
  • Where it happened: 8D panel, 8D Overview, 8D Coach or MCP tools.
  • A screenshot with any private details hidden.

Before you write

The docs cover setup, the 8D steps, the Coach and the MCP tools. Security issues go through the private route on the security page.
