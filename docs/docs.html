How to set up Eight-D and run an 8D with it.

Install

Install Eight-D on your Jira Cloud site from the Atlassian Marketplace (listing coming soon). A site admin approves the permissions listed on the security page.

Run an 8D

  1. Open the Jira work item that holds the problem (a customer complaint or a nonconformance).
  2. Find the 8D panel and press Open full 8D.
  3. Work through the steps in order: D1 team, D2 problem (5W2H), D3 containment, D4 root cause, D5 corrective actions, D6 implement and validate, D7 prevent recurrence, D8 close.
  4. Press Approve when a step is done. The approver and date are stored. Reopening a step reopens every later one.

The 8D Overview page (Apps menu) lists every open 8D you can see, with the current step, the D3 containment clock and days open. On an empty site it offers demo data for synthetic parts.

8D Coach (Rovo)

Ask the 8D Coach agent in Rovo, or press Draft with 8D Coach in the panel. It can draft the D2 problem statement, scaffold a 5-Why, find similar nonconformances, preview corrective actions and a customer report, and list open 8Ds. It only fills text fields with a draft: a person reviews, edits and approves.

Safety: if a work item has the label safety, the panel shows "Safety-related: notify your quality manager", the automation buttons are off, and the Coach drafts nothing.

Use the tools from Claude or another MCP client

Eight-D's six read-only tools are published through Atlassian's MCP server.

  1. A site admin turns on Expose tools for Eight-D on each product install (Jira) in the app's admin settings.
  2. Add the server to your client, for example Claude Code: 
    claude mcp add --transport http eightd https://mcp.atlassian.com/forge/f753cecd-d0ad-48d6-a7a0-58834ff31188
  3. Sign in with your Atlassian account when asked. The tools see only what your Jira permissions allow.

Teamwork Graph connector

On by default. It writes part, machine and supplier-lot objects to Teamwork Graph so similar cases can be found across your site. 8D status objects are written only when TG_STATUS_PUBLIC=true, because connector objects are visible site-wide. If the graph is off, empty or fails, similar-case search falls back to Jira links and Confluence search.

Build it yourself

The source is on GitHub. You need Node 22+, the Forge CLI and an Atlassian developer account.

npm install
npm --prefix static/eightd-ui install
npm run build
npm test
forge register
forge lint
forge deploy
forge install --product jira

Data

8D records live in Forge storage in your site, one per work item. No data leaves Atlassian's platform. Details: privacy policy.
